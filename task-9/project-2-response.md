# [The Culture Vulture Museum](https://yejiweji.github.io/CART263_Project2_-FINAL-/)

The Culture Vulture Museum is an interactive web-based museum that explores “the tension between cultural preservation and consumer consumption.” It showcases how institutions package culture using a profit driven mindset while extracting the culture from its context. The site also features a claw machine game that dispenses fortune cookies to further accentuate this point.

I really love the concept of this project. Right away I loved the fact that the sign-up screen charges users differently based on their racial identity; people of colour are charged more to enter the museum. The ticket page alone serves as a critique to surveillance capitalism as well. As users expose their identity to the system, the system uses that data against the user to generate more profit. I also found it intriguing how when I completed the project, it became ironic how people of colour had to pay more when the museum was based on a racialized person’s identity. The arcade was also a great touch to this project. I love how it simulates the functionality of an actual claw machine since dropping the claw doesn’t guarantee a cookie being picked up. I had a lot of fun with this part since the fortunes were randomized as well.

Yejin and Nancy did a great job at utilising the Phaser 3 library to handle the game mechanics. Their code showcases an understanding of the different possibilities you can achieve when making games with this library. 
# [Escapism](https://philippe-bn.github.io/cart263/projects/project-2/)

Escapism is an interactive 3D fantasy world which creates a meditative experience for the user and allows them to escape from real world problems with no ill intentions of drawing profit or requiring interaction from the user.

This project was so visually and aesthetically pleasing. It really does an amazing job at setting a relaxing and calming atmosphere the user. I love how the I could freely explore the world in this project—I felt fully in control on what I wanted to experience and how I wanted to experience it. Although it was a virtual world, it made feel reconnected with nature because of the lush greenery, the massive flock of birds and the expansiveness of the whole scene. I felt truly at ease thanks to the visuals and aesthetics of this project.

This project effectively uses a variety of addons from the THREE js library to create compelling and beautiful visuals. Philippe and Ben used the sky and Improved noise add ons from the Three js library to their advantage to make their project look like a real life yet fantastical landscape.  

# [Snake 3D](https://yaxuanpang.github.io/cart263/topics/project2/)

Ashmitha, Ya Xuan and Nerly created a 3D snakes game that follows the same rules as the conventional 2D snakes games with the obvious twist that it is no longer 2D but 3D and it more importantly, it allows the player to generate more targets that the snake can consume.

This game brought a really fun twist to the conventional 2D snakes game. I loved to see the evolution from the previous snakes game from this team and I think the visual aesthetics really improved in this project. I found It very innovative to implement the microphone in the gameplay because it offers and unexpected layer of interaction for the user. The overall experience was very enjoyable yet challenging due to the controls being confusing based on different camera angles.

The code for this game was very clear and understandable. It also made me realize it is possible to create a class within the same js file (at first I thought classes were required to be made in a different file but now I understand it is mainly done for organization purposes). This project mainly uses the Three js library obviously because it is a 3D game and as I mentioned previously, it also uses the inbuilt microphone function to fetch the users audio input to create more targets for the snake.
